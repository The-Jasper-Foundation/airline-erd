# Airline booking database — ER modelling practice

**Live page:** https://the-jasper-foundation.github.io/airline-erd/

A small airline booking database designed to answer three client questions:

1. Which customers should get a price-change alert?
2. Which countries do an airline's bookings come from?
3. Which December flights offer a child fare and a kids' meal?

| File | What it is |
|---|---|
| `index.html` | Interactive UML diagram — click a question to see the tables it uses |
| `airline_worked_example.sql` | 10 tables, mock data and the three queries (MySQL 8) |

## Run it

Open `airline_worked_example.sql` in MySQL Workbench (or any MySQL 8 client) and run the whole script. The three result tables appear at the end.

## Context

A practice exercise from the Database Design and Implementation module at Anglia Ruskin University. Built with Claude as a study aid. All data is invented.
